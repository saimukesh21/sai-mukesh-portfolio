# Sai Mukesh B | Portfolio

Personal portfolio for an AWS DevOps Engineer (fresher): CI/CD, Kubernetes on EKS, Terraform and cloud security automation.

Live site: https://sai-mukesh-portfolio-mu.vercel.app/

## Stack
Static site: one `index.html` (no build step), deployed on Vercel.

## Features
Dark and light theme, skills filter, scroll progress, mailto contact form, JSON-LD and Open Graph metadata, print-friendly styles.

## Run locally
    npx serve .

## Files
- `index.html` the whole site
- `Sai_Mukesh_B_Resume.pdf` linked from the Download resume button
- `vercel.json` clean URLs and security headers
